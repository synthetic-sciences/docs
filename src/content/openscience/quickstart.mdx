You can start with a provider key or a local model. An Atlas account is optional.

<Steps>
  <Step title="Install OpenScience">
    ```bash
    npm install -g @synsci/openscience@latest
    ```

    You can also run `npx synsci` without a global install. The shell installer, `curl -fsSL https://openscience.sh/install | bash`, places a standalone binary in `~/.openscience/bin`. Platform binaries are published on [GitHub Releases](https://github.com/synthetic-sciences/openscience/releases).

    Linux requires kernel 5.1 or newer. Glibc builds require glibc 2.17 or newer. Separate musl builds are available.
  </Step>

  <Step title="Configure a model">
    ```bash
    export ANTHROPIC_API_KEY=sk-ant-...
    ```

    Replace this with the environment variable for your provider. You can also run `openscience keys add`, use the Credentials panel, or register a local server with `openscience local add`. See [Models and providers](/openscience/models).
  </Step>

  <Step title="Open your project">
    ```bash
    openscience ~/code/my-project
    ```

    OpenScience starts a local server and opens the project in your browser. The workspace has files, an editor, sessions, scientific previews, compute status, and artifact history. Project commands still run in your system terminal.
  </Step>

  <Step title="Run a focused task">
    State the outcome, relevant inputs, and any cost or runtime limit.

    ```text
    Reproduce the main result of arXiv:2305.13245 on a 125M parameter model.
    Use no more than one GPU for 90 minutes. Save the config, metrics, and plot.
    ```

    For a one-shot terminal run:

    ```bash
    openscience run "Profile train.py and identify the input pipeline bottleneck"
    ```
  </Step>

  <Step title="Connect Atlas if you need it">
    ```bash
    openscience login
    ```

    Atlas adds credential sync, managed models, shared research graphs, and GPU leases. OpenScience remains usable without it. See [Connect to Atlas](/openscience/atlas).
  </Step>
</Steps>

## Check the installation

```bash
openscience --version
openscience models
openscience skill list --all
```
