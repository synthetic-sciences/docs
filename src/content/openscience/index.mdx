OpenScience is a local workspace for computational research. It combines an agent runtime, project files, scientific data connectors, execution tools, and artifact history in one browser interface.

Give it a concrete research task. It can search papers and scientific databases, inspect a repository, write and run code, dispatch approved compute jobs, and assemble the result in the same project. You choose the model and control every paid or destructive action.

```bash
npm install -g @synsci/openscience@latest
openscience
```

The bare `openscience` command starts the local server and opens the workspace. `npx synsci` runs it without a global install. No account is required.

## Use your preferred model

Bring a provider key, sign in through a supported provider flow, or connect a local OpenAI-compatible server.

```bash
export ANTHROPIC_API_KEY=sk-ant-...
openscience
```

With your own key, requests go directly from your machine to the selected provider. Local models and provider keys do not require Atlas. See [Models and providers](/openscience/models) and [Local models](/openscience/local-models).

## Atlas is optional

[Atlas](/atlas/index) adds synced credentials, managed model billing, shared research graphs, and a GPU marketplace. Standalone OpenScience keeps its sessions and files local. See [Connect to Atlas](/openscience/atlas) for the exact boundary.
